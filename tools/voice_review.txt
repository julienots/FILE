# Revue fine de la prononciation (tools/voice_verify.py, whisper-medium, les 870 phrases, homophones exclus).
# 3 phrases sur 870 ont encore un mot que le modèle entend différemment ; les 867 autres sont transcrites sans écart.
# Un écart est souvent une erreur de transcription (hausse → osse, les sons → laissons : mêmes sons) plutôt qu'un défaut de voix : à écouter en priorité pour trancher.
# Format : mots en écart | texte voulu | transcription du modèle
hausse→osse | Hausse les épaules vers les oreilles... et laisse-les retomber, lourdement. | Osse les épaules vers les oreilles et laisse les retomber lourdement.
laiteuse→léteuse | La Voie lactée traverse le ciel, comme une rivière laiteuse. | La voie lactée traverse le ciel comme une rivière léteuse.
sons→laissons, sons→laissons | Les sons proches... les sons lointains... et le silence entre eux. | Les laissons proches, les laissons lointains et le silence entre eux.
