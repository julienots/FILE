# Pack de skills Super Essence Studio

Trois skills, à installer sur chaque compte Claude :

1. `preview-avant-build` : fiche concept, comparatif et maquette légère avant de coder.
2. `splash-super-essence` : intro du studio avec le logo officiel, puis l'écran de chargement du projet. Contient le logo et une démo dans `assets/`.
3. `qualite-jeu-mobile` : grille de contrôle et tests automatiques avant livraison.

## Installation
- Claude (web, appli, bureau) : Réglages, Capacités, Skills, puis importer chaque dossier zippé séparément (un zip par skill, avec le dossier à la racine).
- Claude Code : copier les trois dossiers dans `~/.claude/skills/` (pour tous les projets) ou dans `.claude/skills/` du projet.

L'emplacement exact du menu peut changer selon la version de l'appli.

## Ordre d'utilisation
preview-avant-build → (OUI de ta part) → splash-super-essence → construction par passes → qualite-jeu-mobile à chaque passe.
