# VOXÉA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** APK Android qui transforme un script texte en un MP3 par réplique, à partir de la voix de l'utilisateur lue dans un prompteur.
**Architecture:** Module Gradle `:voxea` (package `com.superessence.voxea`). Logique pure Kotlin testée en JVM (parsing, DSP, WAV, MP3) ; UI Compose ; stockage JSON par projet dans filesDir.
**Tech Stack:** Kotlin 2.1, Compose BOM 2025.06, kotlinx-serialization, jump3r (MP3), HttpURLConnection (ElevenLabs).
**Spec:** docs/superpowers/specs/2026-11-28-voxea-design.md

## Global Constraints
- minSdk 26, targetSdk/compileSdk 35, applicationId `com.superessence.voxea`, signé avec keystore/noctea-release.jks.
- Aucune clé dans le code ; clé ElevenLabs saisie dans Réglages, stockée en SharedPreferences privées.
- Nom des fichiers exportés : `NN_PERSONNAGE.mp3` (NN sur 2 chiffres, nom ASCII majuscule), dossier Music/VOXEA/<projet>.
- Palette du projet distincte de celle du studio (jaune #FCCC24 réservé à l'intro studio).

## Review Focus
1. Script sans `NOM :` (texte brut) → chaque paragraphe non vide = une réplique « NARRATEUR ».
2. Ligne `NOM : texte` avec deux-points dans le texte (« Il dit : non ») → seul le premier `:` après un nom court (≤ 30 car., pas de point final) sépare.
3. Réplique non enregistrée au moment de l'export → ignorée et signalée, pas de crash.
4. Enregistrement très court/silencieux (< 0,2 s) → DSP renvoie le signal sans planter.
5. Permission micro refusée → message clair et bouton réglages, pas de crash.

**Files:** settings.gradle.kts (include ":voxea"), voxea/build.gradle.kts, voxea/src/main/AndroidManifest.xml, `voxea/src/main/java/com/superessence/voxea/core/Script.kt`, test `voxea/src/test/.../ScriptTest.kt`
**Produces:** `enum class VoiceType { ORIGINAL, FEMME, HOMME, ENFANT, AGE, ROBOT }`; `data class Line(val index:Int, val character:String, val text:String, val voiceHint:VoiceType?)`; `object ScriptParser { fun parse(raw:String): List<Line> }`.
- [ ] Tests : `"LÉA : Salut"` → character "LÉA", text "Salut"; `"MARC [HOMME]: Ok"` → hint HOMME, character "MARC"; texte brut 2 paragraphes → 2 lignes NARRATEUR; `"Il dit : non."` ligne longue sans nom → narrateur (Review Focus 1-2); `"LÉA (femme) : x"` → hint FEMME; didascalies `(rire)` conservées.

### Task 2: DSP de transformation de voix
**Files:** `core/VoiceDsp.kt`, `core/VoicePreset.kt`, test `DspTest.kt`
**Produces:** `data class VoiceSettings(val pitch: Float /*demi-tons*/, val formant: Float /*ratio*/, val robot: Boolean=false)`; `fun VoiceType.defaultSettings(): VoiceSettings` (FEMME +5 st / 1.18, HOMME −5 / 0.86, ENFANT +8 / 1.30, AGE −2 / 0.94 + vibrato léger, ROBOT 0 / 1.0 robot, ORIGINAL 0 / 1.0); `object VoiceDsp { fun process(pcm: FloatArray, sampleRate:Int, s: VoiceSettings): FloatArray }`.
- Algorithme : vocodeur de phase STFT (N=2048, hop=N/4, fenêtre de Hann) ; par trame, enveloppe = lissage cepstral (30 coefficients) ; excitation = |X|/env ; décalage de hauteur par ré-échantillonnage des bins de l'excitation avec phase cohérente (méthode Laroche-Dolson, verrouillage aux pics) ; enveloppe ré-échantillonnée par facteur formant ; recombinaison, overlap-add, normalisation crête −1 dBFS.
- [ ] Tests : sinus 200 Hz, pitch +12 → fréquence dominante 400 Hz ±5 %; durée de sortie = durée d'entrée ±1 %; pitch 0/formant 1 → corrélation > 0.95 avec l'entrée; entrée 0,1 s → pas d'exception (Review Focus 4).
- [ ] Implémenter, tests verts, commit.
