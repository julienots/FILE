Hors ligne
Préparation…
  1. 1. Autoriser AXON à utiliser l'écran Paramètres › Accessibilité › Applications installées › AXON CONNECT › Activer.
    Si Android affiche « Paramètre restreint » : Paramètres › Applications › AXON CONNECT › ⋮ › Autoriser les paramètres restreints, puis réessayez.
  2. 2. Relais Internet
  3. 3. Relier à Claude Copiez l'adresse, puis dans Claude : Paramètres › Connecteurs › Ajouter un connecteur personnalisé › nom « AXON » › collez › Ajouter. Dans une conversation, activez AXON dans le menu des outils.
  4. 4. Autres appareils (facultatif)Envoyez ce lien :
    • à un autre téléphone à piloter : dans son app AXON › « Claude pilote cet appareil » › Réglages avancés › Rejoindre. Claude les pilote tous, un par un ou en même temps, avec un seul connecteur ;
    • à une tablette : elle voit tous les appareils en direct (navigateur ou app AXON).

    Collez le lien « Partager » d'un téléphone AXON : cet appareil rejoint son salon, et Claude les pilote ensemble avec le même connecteur.
